# RAVINS — THE LEGACY

A responsive family graduation tribute website for George Okello Otieno ("Ravins").

## Project structure

- `index.html` — page content and structure
- `CSS/style.css` — Midnight Gold visual design and responsive layout
- `JS/script.js` — countdown, navigation, reveal effects, gallery lightbox and surprise message
- `images/` — supplied photographs

## Run locally

1. Keep the folder structure unchanged.
2. Open `index.html` in a modern browser.
3. For development, use VS Code with the Live Server extension if available.

## Before publishing

- Confirm the exact wording of the qualification and graduation details.
- Replace or edit the family message so it reflects the family's own words.
- Add more family and graduation photographs to `images/`, then add matching gallery entries in `index.html`.
- Check all personal information before making the site public.

## GitHub Pages deployment

1. Create a GitHub repository, for example `ravins-graduation`.
2. Upload the contents of this folder (not the outer folder itself).
3. In the repository, open Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

The website uses a free Google Fonts connection; if the visitor is offline, fallback fonts will display.
